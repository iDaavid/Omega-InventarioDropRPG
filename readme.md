Este es el inicio de nuestro proyecto de Gestion de Inventario basado en RPG's

Integrantes:
- David Herrera
- Mahlon Romero 
- Carlos Chinchilla 
- Luis Bernay

Tematica:
Simular la logica de servidor y mostrarla visualmente de un juego de rol, enfocandose en dos de las mecanicas principales: almacenar los recursos obtenidos y calcular la probabilidad matematica (RNG) para conseguir un item en especifico de un jefe al ser derrotado.

Lenguaje: Python 

## Dependencias
El proyecto utiliza Flet para la interfaz gráfica. Para instalar las dependencias necesarias, ejecuta el siguiente comando en la terminal:
```bash
pip install flet
```

## Instrucciones de Uso
1. Asegúrate de tener instalado Python en tu sistema.
2. Clona el repositorio o descarga los archivos.
3. Instala las dependencias como se indicó anteriormente.
4. Ejecuta el archivo principal para iniciar la aplicación:
```bash
python main.py
```
5. Explora las zonas en la interfaz, selecciona un jefe para enfrentarlo y observa los items obtenidos que se almacenarán en tu inventario.
